## How to use a lab

Each lab is a **self-contained folder** under [`labs/`](labs/):

| File | Purpose |
|---|---|
| `README.md` | Full step-by-step lab instructions |
| `INSTRUCTIONS.md` | Quick start — how to run the lab |
| `checklist.md` | Completion / verification checklist |
| `scripts/run.sh` | All lab commands assembled into one runnable script |
| `lab-NN-slug.pdf` | Printable PDF of the lab |

1. Open the [Killercoda Ubuntu Playground](https://killercoda.com/playgrounds/scenario/ubuntu).
2. Follow the lab's `README.md` step by step.
3. Work through `checklist.md` to confirm the outcome.
4. Reset the playground between labs that change firewall, PAM or routing state.

See [`labs/README.md`](labs/README.md) for the full index of all 43 labs by domain.
